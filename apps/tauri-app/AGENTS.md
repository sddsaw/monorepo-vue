# 工业工作台 UI 约定

修改界面时参考 `../../docs/tauri-app/UI设计规范.md`。

- 颜色、字体、字号、圆角继续由现有 theme Store 管理，直接使用现有变量，不再包装同义 Token 或增加主题状态。
- 字号和控件高度复用 `src/theme/typography.ts`、`text-ui-*`、`min-h-ui-*`；Naive UI 优先使用自带尺寸和主题配置。
- 间距、文字层级、表格密度及交互遵循规范；先用现有工具类和局部样式，有实际重复需求再提取共享值。
- 按当前任务范围修改组件，保留其他未提交工作；不为统一外观重写业务逻辑、Dockview 几何或缩放机制。
