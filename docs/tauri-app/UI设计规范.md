# Tauri 工业工作台 UI 设计规范

适用范围：`apps/tauri-app`。目标是让文字、间距、控件和密集数据呈现一致，复用现有主题和样式能力。

## 1. 实现边界

| 内容 | 唯一实现入口 |
| --- | --- |
| 主色、明暗、背景、文字、字体、圆角及保存 | 现有 theme Store、`theme/settings.ts`、主题预设 |
| 字号与控件高度缩放 | `src/theme/typography.ts` |
| 模板中使用尺寸与字号 | `uno.config.ts` 已有的 `text-ui-*`、`h-ui-*`、`min-h-ui-*` |
| Naive UI 外观与尺寸 | Store 中的 `getNaiveTheme()`、`getTypographyTheme()` 与组件 `size` 属性 |
| 组件的排版和间距 | UnoCSS 工具类或组件局部 CSS，按下列尺度选值 |

直接使用现有 `bg-container`、`text-base-text`、`--border-color`、`--hover-color`、`--active-color` 等样式接口。现有变量已能表达的含义，不增加同义别名。不另建 Token 文件、密度 Store、配色表或生成器。

本规范是新开发和修改组件时的选值约定，不会自动重排所有旧页面，也未增加密度切换设置。涉及第三方布局、坐标或缩放时，保留现有适配代码。

## 2. 文字层级

下表是用户正文字号为 **14px** 时的设计基准，实际显示随用户设置缩放。

| 用途 | 基准字号 | 使用方式 |
| --- | --- | --- |
| 次要说明、单位、表格辅助内容 | 12px | `text-ui-12` |
| 树节点、密集表格内容 | 13px | `text-ui-13` |
| 正文、表单标签、主要数据 | 14px | `text-ui-14` |
| 面板标题 | 16px | `text-ui-16` |
| 页面级标题，工作台内少用 | 20px | `text-ui-20` |

- 字重采用 400 正文、500 标签、600 标题；正文行高 1.5，单行紧凑标签可用 1.4。
- 不把正文写成固定 `font-size: 14px`；模板复用上述工具类，脚本确需计算时调用已有 typography 工具。
- 用户正文字号范围仍为 12–18px；已有辅助字号算法下限为 11px，本次不修改算法。新内容以至少 12px **基准字号**设计，关键结果和告警使用正文层级，检查缩小字号后的可读性。
- 界面字体跟随现有 `font-sans`；数字列需要对齐时使用 `tabular-nums`，日志或代码片段可使用 `font-mono`。

## 3. 间距

| 间距 | 用途示例 | 工具类示例 |
| --- | --- | --- |
| 2px | 紧邻细节、指示标记 | `gap-2px` |
| 4px | 图标与文字、紧凑单元格纵向留白 | `gap-4px`、`py-4px` |
| 8px | 控件之间、单元格横向留白 | `gap-8px`、`px-8px` |
| 12px | 紧凑面板内边距、表单项之间 | `p-12px`、`gap-12px` |
| 16px | 常规面板内边距、分组之间 | `p-16px`、`gap-16px` |
| 24px | 独立内容区之间 | `gap-24px` |
| 32px | 大区块分隔，工作台内少用 | `gap-32px` |

优先选用以上尺度，特殊几何可以局部说明原因。间距不随字体机械地同比放大；文字与控件可以撑开容器，避免固定高度裁切。不要为了包装 `8px` 再创建多层变量。

## 4. 控件、表格和树

以下为 14px 字号下的尺寸基准，不是新的全局密度模式。

| 对象 | 默认约定 | 现有实现方式 |
| --- | --- | --- |
| 工作台按钮、输入框 | 28px 基准高度 | Naive UI `size="small"`；自定义控件 `min-h-ui-28` |
| 常规表单控件 | 34px 基准高度 | Naive UI `size="medium"`；自定义控件 `min-h-ui-34` |
| 工具条、面板标题区 | 32px 最小高度 | `min-h-ui-32`，允许换行撑高 |
| 表格行、树节点 | 28px 起，带编辑控件的行由内容撑高 | 单行容器 `min-h-ui-28`；原生表格在 `td/th` 使用 `h-ui-28` |
| 表格单元格 | 纵向 4px、横向 8px | `py-4px px-8px` |
| 树层级缩进 | 每层 16px | 使用组件已有缩进配置 |
| 内容图标 | 16px 基准 | `text-ui-16`，保持相邻图标一致 |

- 原生 `td/th` 的 `height` 作为最低行高参考；不要依赖 `tr` 的 `min-height`。组件库表格使用其 `size` 和公开配置，不覆盖内部结构来模拟全局密度。
- 较大字号通过现有高度算法增大控件，小字号不缩小点击区域。固定 `h-ui-*` 只用于明确单行的内容；多行容器优先 `min-h-ui-*`。
- 图标大小与点击区域分开：自定义独立图标按钮默认至少 28×28px，随文字增长；触屏部署另行保证至少 44×44px。
- 宽表在自己的容器内横向滚动；数值右对齐，单位置于列头或明确字段。缺失值显示「—」，不能当作 0；显示精度由业务决定。

## 5. 边界与交互规则

- 分隔线通常 1px，颜色使用已有边框变量。可编辑控件边界、正文与焦点按实际明暗主题检查对比度。
- 自定义控件圆角使用现有 `var(--theme-radius)`；Naive UI 继续使用主题配置。连续拼接的工作区面板可以直角，不再维护第二套圆角设置。
- hover 使用现有悬停色，selected 使用现有选中色；二者同时存在时选中标识必须保留。分屏中要能区分当前活动组。
- disabled 阻止操作但不能让重要数据不可读；loading 阻止重复提交并显示反馈；错误提供就地说明；键盘 `focus-visible` 保持清晰，不能只靠 hover。
- 设备状态、告警和故障必须有文字或图标；配色复用现有语义色，由具体业务确定映射，本规范不另设状态色表。
- 新增轻量颜色过渡建议 150ms，面板过渡不超过 200ms；明确列出过渡属性，避免 `transition: all`。自定义动画响应 `prefers-reduced-motion`，不对高频测量数据逐项做动画。

## 6. 使用示例与维护

```vue
<template>
  <section class="bg-container p-12px text-base-text text-ui-14">
    <h2 class="mb-8px font-600 text-ui-16">测试参数</h2>
    <div class="flex flex-wrap items-center gap-8px">
      <NInput size="small" aria-label="测试项名称" />
      <NButton size="small" type="primary">保存</NButton>
    </div>
  </section>
</template>
```

每次只迁移任务涉及的组件。检查明暗主题、12/14/18px 字号下的裁切、键盘焦点，以及表格和面板缩窄后的行为。先复用既有接口；只有多个实际消费者需要共享且现有实现无法表达的值，才在最靠近它们的公共位置提取，避免预先设计未使用的配置系统。
