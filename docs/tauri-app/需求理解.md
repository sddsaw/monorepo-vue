| R07 | P0 | 保存成功只清除本次写入已覆盖的修改标记；保存期间的新修改仍显示未保存，旧工程的保存结果不能改变新工程状态。连续保存不得发生旧内容晚写入并覆盖新内容。 |
| R08 | P0 | 保存失败保留内存数据和未保存标记，显示失败原因并允许重试；多文件部分成功时不能显示整个工程保存成功。 |
| R09 | P0 | 关闭工程、切换工程或退出桌面应用前，存在未保存修改时提供“保存 / 放弃 / 取消”。保存失败或仍有新增未保存修改时不直接离开；取消保留当前工程；放弃后才继续操作。 |
| R10 | P0 | 单纯关闭编辑标签不等于关闭工程，沿用现有标签关闭确认约定；关闭后重新打开标签，仍可看到 Store 中尚未保存的修改。 |
| R11 | P1 | 保存操作有明确的进行中、成功或失败反馈；重复点击和快捷键使用同一保存入口，反馈对应实际结果。 |

#### 数据与更新约束

- 保持一份已提交的工程业务数据；表格通过数据选择逻辑读取，局部草稿在确认后提交。
- 所有业务写入统一经过 Store action，避免组件直接修改原始对象而绕过通知、校验和修改记录。
- shallowRef 的内部字段修改需要显式通知。优先按源文档或业务模块划分订阅范围；跨面板依赖同一数据时必须订阅同一更新来源。
- 不能假设父组件持有同一个对象引用就会使子组件自动刷新。数据选择、computed 和 props 链路必须完整覆盖更新信号。
- 区分视图刷新版本和保存修改版本，不能因为界面刷新而清除未保存标记。
- 视图同步表示各消费者读取同一数据源的最新值。管脚改名后修改其他文档中独立保存的名称字符串属于业务引用迁移，需另行明确引用规则，本期不自动推断。

#### 非功能需求

- 性能：使用代表性的约 10 MB 单文件及多文件工程验证。单字段编辑不得深拷贝、序列化或深度遍历整个工程；批量编辑合并通知，避免每个单元格触发所有面板重算。
- 校验：评估现有全工程校验成本，单字段编辑优先检查受影响数据；不得以优化为由漏掉已有必要校验。保存时是否允许带校验问题写入沿用现有业务约定，不擅自改变。
- 展示：大表格复用现有虚拟滚动或分页能力；记录实际渲染行数，避免将全量行渲染问题误判为 Pinia 问题。
- 测量：记录验证设备、工程大小与行数、面板数，以及加载耗时、编辑到视图更新的耗时、保存耗时和内存变化；本需求不虚构固定延迟或内存验收阈值。
- 文件完整性：写回须保留未编辑字段和文档结构。检查现有原生写入方式，避免失败时把目标文件截断成损坏 JSON；每个文件的安全替换不等于多文件事务。
- 可维护性：统一封装订阅与取消订阅，关闭面板后不遗留监听；兼容嵌套对象、数组增删和整段对象替换。

#### 边界与依赖

- 不实现自动保存，不因编辑、失焦或定时器直接写磁盘；失焦只提交内存编辑。
- 不新增撤销重做、多用户协作、跨窗口状态同步、多个工程并行编辑或外部文件冲突合并。
- 桌面文件写入复用 Tauri 能力；浏览器预览若不支持写回，应明确提示并保留未保存状态。
- 不将整个工程持久化到 localStorage，不另建第二份可写工程 Store。
- 改动范围为工程 Store、共享数据订阅、现有编辑器接入、保存入口及必要的离开保护；不重做界面布局。

#### 验收标准

| 编号 | 输入与操作 | 预期结果 |
| --- | --- | --- |
| A01 | 打开有效工程，再尝试打开无效工程 | 有效工程正常展示；后一次加载失败不会留下混合或半加载数据。 |
| A02 | 修改单元格并确认，同时打开另一个依赖该字段的面板 | Store 和两个面板展示新值；出现未保存标记；源文件内容保持不变。 |
| A03 | 输入后按 Esc，或提交无效值、未变化的值 | Esc 不修改 Store；无效输入可纠正并有提示；无实际变化不新增修改记录。 |
| A04 | 修改共享定义，检查引用该定义生成的选项与统计 | 已打开的相关消费者更新；无需重开面板；不擅自改写其他文档中的独立字符串。 |
| A05 | 增删数组行、替换嵌套对象、执行已有批量编辑 | 数据选择结果和子组件一致；批量动作不逐字段触发全工程刷新。 |
| A06 | 单元格仍处于编辑状态时按保存快捷键 | 有效草稿先提交再保存；无效草稿阻止本次保存并提示。 |
| A07 | 修改一个定义文件后手动保存，再重新加载 | 对应文件包含新值且未编辑字段保留；无关源文件不被重写；聚合数据不覆盖 .prx。 |
| A08 | 修改后持续操作和等待，不点击保存 | 源文件内容不变，无自动写入请求。 |
| A09 | 在保存过程中继续编辑，再连续触发保存 | 新修改不会被旧保存结果清除；最终文件为最后一次成功保存对应的内容。 |
| A10 | 模拟写入失败或多文件部分失败后重试 | 内存修改保留，有失败提示，不误报全部成功；重试后文件正确。 |
| A11 | 存在修改时关闭或切换工程，分别选保存、放弃、取消 | 保存完成且无遗漏修改才离开；失败则留下；放弃继续；取消保持原工程。 |
| A12 | 关闭编辑标签后重新打开；反复开关面板 | 未保存数据仍存在；监听数量不持续累积。 |
| A13 | 用约 10 MB 工程完成编辑、跨面板同步、批量操作和保存 | 功能正确并提供性能测量记录；单字段编辑不发生全工程复制或序列化。 |
| A14 | 在浏览器预览中尝试保存 | 如无写入能力，明确提示并保留未保存状态。 |
